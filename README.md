# 时格

**把一天切成格子来安排。** 上午 / 下午 / 晚上三个时段排计划，顺手打卡习惯、写每日复盘，还有一个常驻桌面的小浮窗。

月 / 周 / 日三种视图，习惯打卡、每日评价、专注计时、倒数日、统计分析。

**适用场景**：日常计划安排、学习任务管理、习惯养成追踪、每日复盘总结。

**主要特点**：本地优先（无需联网、无需账号）、桌面常驻浮窗、Windows 免安装 exe、安卓 apk、数据可完整备份导入导出。

## 📦 桌面版与安卓版（推荐，完全本地）

不依赖任何服务器，数据保存在本机的应用数据库里，**不需要科学上网、不需要注册账号**。

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `TimeGrid-0.8.0-portable.exe` | 便携版，双击即用，不写注册表、不需要管理员权限 |
| Android | `TimeGrid-0.8.0-android.apk` | 安装包，7.0（API 24）及以上；首次安装需允许「安装未知来源应用」 |

> 两个文件都在 [Releases](https://github.com/2016469520/plan-calender/releases/latest) 页面，手机可以直接扫码或点链接下载。

### 桌面浮窗（Windows）

启动后会同时出现两个窗口：主窗口 + 右下角的浮窗。

- **两个标签页**：清单 / 专注，浮窗里就能直接开番茄钟
- **随时找回**：主界面左侧栏底部有「桌面浮窗」开关（显示中 / 已隐藏），设置 → 外观 里也有同样的开关；系统托盘菜单同样可以显示或隐藏
- **三种添加方式**：输入框回车、点输入框左边的 `+`、或点右边「新建」打开完整表单（可选时段、标签、起止时间）
- **点一下就能改**：点清单里的任意事项打开编辑面板，可改标题/时段/标签/时间，也能标记完成或删除
- **常驻桌面**：默认置顶，可以一直看着今天的清单；直接勾选圆圈即可完成，和主窗口实时同步
- **拖动与缩放**：拖标题栏移动，拖边角改大小，位置和尺寸会记住；换过显示器导致跑出屏幕时会自动拉回可视区域
- 托盘图标（右下角系统托盘）可以随时显示或隐藏浮窗；**关闭主窗口只是收起**，应用仍在托盘运行，彻底退出走托盘菜单的「退出」

### 专注（番茄钟）

- **1 分钟粒度**：`− / +` 点一次加减 1 分钟，按住连加，Shift 点击一次 5 分钟；也支持滚轮、滑块、直接输入
- **预设**：5 / 15 / 25 / 45 / 60 / 90 分钟，点一下就选定
- **倒计时**：环形进度 + 剩余时间，专注中还能「+1 分钟」加时
- **正计时**：先做起来再说；可以设 15 / 25 / 45 / 60 分钟目标，进度环会随着专注填满，超出目标后变成桃红并显示 `+超时`
- **跨窗口同步**：在浮窗里开始或暂停，主窗口的专注状态会同步过来

### 使用说明

1. **Windows**：双击 exe 直接打开。关闭主窗口会收起到托盘 + 保留浮窗，需要完全退出请用托盘菜单「退出」。
2. **Android**：把 apk 传到手机后点击安装（微信/QQ 传文件时选择「用其他应用打开」→ 安装包）。
3. 数据默认存在本机；**换手机或重装前请先备份**：设置 → 数据 → 完整备份 → 导出 JSON。
   在新设备上用「从备份恢复」导入即可。

> 桌面版和安卓版的数据互不相通（各自独立存储），通过上面的备份文件在设备之间搬运。

### 如何使用

#### 日程主页（默认首页）

1. 登录后自动进入「日程」主页，直接看到今天的所有计划
2. 顶部输入框快速添加事项，不需要打开弹窗
3. **桌面端**：点击事项在右侧打开详情面板，可直接修改字段
4. **手机端**：点击事项进入全屏详情
5. 切换视图：今天 | 近期 | 全部 | 按分类

#### 日历视图

从主导航进入「日历」，支持月/周/日三种时间视图和拖拽排序。

#### 查看历史评价

1. 在日历页面左侧菜单点击「复盘记录」进入评价历史
2. 点击「月历」按月份查看评价分布；点击日期查看或补写评价
3. 点击「时间线」按时间倒序浏览所有评价，支持按月份、评分、心情筛选
4. 在「今日」页面评价卡片下方点击「查看历史评价」
5. 在「统计」页面点击「查看全部评价」

#### 按分类查看日程

1. 在日历页面顶部点击「按分类」切换到分类视图
2. 事项按标签自动分组，每个分类显示事项数量和完成率
3. 点击分类头部的 + 按钮新建事项，自动预选该标签
4. 开启「隐藏空分类」只显示有事项的分类
5. 点击事项卡片上的「移动到」将事项移到其他分类

### 主要功能

- **三种日历视图**：月视图、周视图（上午/下午/晚上）、日视图
- **分类视图**：按标签分类查看事项，支持折叠、筛选、完成率展示
- **事项管理**：创建、编辑、删除、完成切换、优先级、预计用时
- **标签系统**：为事项分类，支持自定义颜色、图标和排序
- **跨分类移动**：将事项在不同分类间移动（桌面/手机均可操作）
- **收集箱**：先记下没有日期的想法，再一键安排到今天或明天
- **拖拽排序**：在时段内调整顺序，跨时段/跨日期移动事项
- **重复日程**：每天、工作日、每周、每月、每年，支持间隔与结束条件（按次数/按日期）；编辑弹窗内可设，标记完成时自动生成下一次，实例指回同一系列
- **子任务**：将大事项拆分为多个子步骤
- **搜索筛选**：日程页「搜索」按钮或 Ctrl+K 打开，支持关键词、状态、优先级、标签、日期范围、过期与重复筛选
- **习惯打卡**：支持完成/未完成、次数、分钟、小时、自定义数值多种计量方式，每种方式有专属输入控件。分钟型支持鼠标滚轮连续调整（每次 ±1 分钟，停止滚动后自动保存）、+/- 微调按钮、直接输入编辑。次数型可+1/-1或直接输入。记录可修改和删除。保存失败会提示并可点击重试
- **倒数日**：纪念日、截止日、生日等倒计时，支持每年重复、首页置顶、归档、编辑和删除
- **专注计时**：倒计时与正计时两种模式。时长按 1 分钟微调（按住连加、Shift ±5、支持滚轮与滑块）；正计时可设目标时长，超出后显示补时
- **每日评价**：评分、心情、精力、总结、明日规划
- **复盘记录**：评价月历和时间线，历史评价浏览、编辑、筛选
- **评价统计**：本月平均评分/完成度/心情、连续评价天数
- **数据图表**：最近 7 天完成趋势、时段分布、标签分布、评价评分趋势
- **提醒通知**：浏览器通知提醒即将开始的事项
- **事项模板**：保存常用事项为模板，一键创建
- **延期处理**：批量将过期事项移至今天或明天
- **数据导入导出**：支持 JSON 导入导出、CSV 导出
- **PWA 支持**：可安装到桌面/主屏幕，离线查看
- **响应式设计**：桌面侧边栏 + 手机底部导航
- **深色模式**：浅色/深色/跟随系统

### 配置 Supabase（云端模式）

1. 在 [supabase.com](https://supabase.com) 创建项目
2. 在 Supabase SQL Editor 中按顺序执行以下 migration 文件：
   - `supabase/migrations/001_initial_schema.sql` — 建表
   - `supabase/migrations/002_rls_policies.sql` — RLS 策略 + 新用户触发器
   - `supabase/migrations/003_fix_handle_new_user.sql` — 修复注册 500 错误
   - `supabase/migrations/004_tag_deduplication.sql` — 标签去重和唯一约束
   - `supabase/migrations/005_countdowns.sql` — 倒数日
   - `supabase/migrations/006_focus_sessions.sql` — 专注记录
   - `supabase/migrations/007_difficulty_due_at.sql` — 难度 + 截止时间
   - `supabase/migrations/008_focus_timer_mode.sql` — 正计时模式
   - `supabase/migrations/009_measurement_type_add_minutes_hours.sql` — 习惯计量类型扩展
3. 在 Supabase Authentication 中启用 Email 登录（建议关闭邮箱确认）
4. 创建 `.env.local` 文件：

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
```

5. 重启 `npm run dev`

> **注意**：不要将 `.env.local` 中的密钥提交到 Git 仓库。

### 打包桌面版（Windows exe）

```bash
npm run build:static     # 静态导出到 out/（注入 NEXT_PUBLIC_LOCAL_ONLY=1）
npm run dist:win         # electron-builder 打便携版 exe，产物在 dist/
```

- 桌面壳代码在 `electron/`：`main.cjs` 负责窗口与 `app://` 协议，`serve.cjs` 是纯函数化的静态文件解析（有单元测试）。
- 用 `app://local` 自定义协议加载前端，保证 IndexedDB 有稳定来源，重启后数据还在。
- 想边改边看：`npm run dev` 起前端，另开一个终端 `npm run desktop:dev` 用 Electron 打开 localhost。

### 打包安卓版（apk）

需要 JDK 21 + Android SDK（platform 36 / build-tools 36）：

```bash
npm run android:apk      # 静态导出 → cap sync → gradlew assembleDebug
# 产物：android/app/build/outputs/apk/debug/app-debug.apk
```

- 安卓壳用 Capacitor，`capacitor.config.ts` 指向 `out/`，WebView 来源是 `https://localhost`。
- `android/local.properties` 由本机生成（已在 .gitignore 里），里面写 `sdk.dir=...`。
- 若项目路径含中文，`android/gradle.properties` 里的 `android.overridePathCheck=true` 已放行（AGP 默认会拒绝）。
- 正式发布前建议用 `assembleRelease` 并配置自己的签名密钥；当前是 debug 签名，适合自己安装使用。

| 主题 | 定位 |
|---|---|

| 暗格 Dark Bento | 深色玻璃模块卡 + 冷光网格（仅深色） |

设置 →「外观与个性化」里可以：

- 点预览卡**即时切换**（预览用同一套 CSS 变量渲染，所见即所得）
- 调**强调色**（8 个预设 + 取色器，文字颜色按对比度自动取深/浅）
- 分别调**按钮 / 卡片 / 输入框 / 弹窗**四类圆角
- 调**界面缩放** 80%–150%（走根字号，不拉伸画面）
- 换**字体**、调正文与标题字号倍率
- 调**动画强度**（关闭 / 低 / 标准 / 高）
- 把当前配置**保存成命名预设**，随时一键套用
- 一键**恢复当前主题默认**或**恢复全部默认**
- **导出 / 导入** JSON 配置

每套主题的个人化参数分开保存，切换主题不会互相污染；所有选择自动保存，下次启动恢复。

## 沉浸氛围（第三轮）

除颜色与组件样式外，六套主题各自拥有一套艺术资产，并真实接入运行中的界面：

- **场景**：每套主题 3 张原创 SVG 插画（共 18 张），可在 设置 → 外观与个性化 → 沉浸氛围 里切换、随机轮换或关闭
- **角色**：樱色的看板娘「小葵」（6 种表情）、霓虹的全息 AI「NOVA」（5 态）、像素的冒险者「PIX」（5 态）
  - 表情由真实事件驱动：勾选完成任务会开心并说一句，专注计时开始会进入工作状态，保存失败会提醒你
  - 点一下角色，它会回一句当前状态的台词
- **每日一句**：每套主题 8 条（共 48 条），留白主题引用的是公有领域古籍并标注作者出处；支持换一句与自定义短句
- **开场页**：每天第一次打开首页时展示「场景 + 角色 + 问候 + 每日一句」，可一键关闭且当天不再出现
- **动效**：樱花飘落、星点闪烁、霓虹扫描线、像素粒子、冷光漂移，最多 18 个元素、只跑 transform/opacity；关闭"氛围动画"或系统开启"减少动态"时整层不渲染
- **庆祝**：完成任务时撒一小把彩带（可关闭）

所有美术都是本项目原创的 SVG，随包离线可用、可无限缩放，无第三方素材与网络请求；素材与许可清单见 [docs/ATMOSPHERE_ASSETS.md](docs/ATMOSPHERE_ASSETS.md)。

### 沉浸 / 纯净 两种工作模式

侧栏底部常驻一个开关，随时切换：

- **沉浸模式**：背景、角色、每日一句、氛围动画全开
- **纯净工作模式**：隐藏角色、压暗背景、停止动画，保留主题配色，工作区最大化

设置页里还有：场景切换与每日轮换、角色位置（左下/右下/主视觉/侧栏）与尺寸透明度、背景可见度/模糊/压暗/遮罩/色相/亮度、以及四类独立开关。

### 自定义素材

- **导入角色图**：可多选，按文件名绑定状态（`normal/happy/thinking/working/success/error`），运行时按情绪自动换图
- **导入壁纸**：换成自己的背景，支持与其他主题共用
- **自定义短句**：每套主题最多 20 条
- 图片存在本机独立的 IndexedDB 里，不上传、不联网；换素材不用改代码

素材包约定与文件命名规则见 [docs/ATMOSPHERE_PACKS.md](docs/ATMOSPHERE_PACKS.md)。
### 角色库与智能配色

- **19 个可选用角色**：一人之下（冯宝宝 6 态 / 张楚岚 / 王也 / 诸葛青）、00 后童年经典 12 个（虹猫 / 蓝兔 / 开心超人 / 喜羊羊 / 灰太狼 / 橙留香 / 菠萝吹雪 / 火麟飞 / 雷伊 / 洛洛 / 南宫问天 / 麦当）、时格原创 3 个
- 分类、搜索（角色名 / 作品名 / 标签）、收藏、最近使用、按作品筛选、一键切换
- 每个角色带**推荐主题 / 场景 / 强调色**，点「应用推荐」才生效，不会覆盖你锁定的背景
- 另有 6 个「待导入」推荐位（初音未来 / 钟离 / 雷电将军 / 阿米娅 / 博丽灵梦 / Saber）：没有内置立绘，需要你导入
- **智能配色**：四种模式（主题默认 / 背景取色 / 强调色联动 / 锁定背景）+ 0–100% 协调强度
  - 换一个颜色，背景氛围光、蒙层、卡片、边框、选中态一起协调，而不是只有按钮变色
  - 背景图与角色立绘**不会被整体染色**；背景只做受控的色相偏移（±32° 内，按强度缩放）
  - 自动维护 4.5:1 的文字对比度，主色不够时优先微调按钮底色
