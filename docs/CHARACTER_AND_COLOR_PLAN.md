## 阶段 2 · 智能色彩引擎 ✅ 已完成

### 2.1 模块
- `src/lib/theme/color-engine.ts`：
  - 颜色转换（hex ↔ oklch，用 CSS 原生 `color-mix` + `oklch()` 为主，避免自研不稳定逻辑）
  - 从图片取主色：canvas 降采样 + 颜色量化（k-means 轻量版，32×32 采样点，6 簇）
  - 由种子色生成调色板：primary / onPrimary / primaryContainer / secondary / tertiary /
    background / surface / surfaceVariant / border / textPrimary / textSecondary /
    ambientGlow / backgroundOverlay / selection / hover / disabled
  - 对比度校验（WCAG 4.5:1 / 3:1），不达标自动调明度
- 三种模式：`wallpaper`（背景取色）/ `accent`（强调色联动）/ `locked`（锁背景只调 UI）
- 协调强度 0–100：控制蒙层/渐变/光效/卡片色调的混合比例

### 2.2 全局应用
- 全部通过 CSS 变量落到 `<html>` 内联样式（已有 `applyToDocument` 扩展）
- 背景图片**不整体染色**：用 `--ambient-*` 叠层（渐变 + 光晕 + 轻蒙层），角色图片不加滤镜
- 六套主题的独立视觉语言由主题 CSS 提供，引擎只改"色相与明度倾向"，不改结构

### 2.3 设置页
- 配色模式四选一（主题默认 / 背景取色 / 强调联动 / 锁定背景）
- 调色板可视化（主色/推荐/次级/氛围/卡片/文字）
- 协调强度滑块、实时预览、撤销、恢复默认、重新取色
- 持久化进现有 `timegrid:appearance:v1`（version 3，旧配置自动补默认）
