> 本项目的全部氛围素材（场景插画、角色、装饰）均为**本项目原创的程序化 SVG**，
> 由本项目代码直接绘制（`src/components/atmosphere/art/*.tsx`），不包含任何第三方
> 图片、截图、字体或受版权保护的角色形象。
>
> 因此这些素材随软件一起分发不涉及第三方授权；也没有任何需要署名或付费的条目。
> 所有素材都是矢量、随包本地化，离线可用，不需要联网加载。

## 生成与维护方式

- 每个场景/角色是一个 React 组件，返回纯 SVG（`viewBox` + 图元）
- 颜色取自对应主题的 CSS 变量或固定调色板，因此能跟随明暗模式
- 修改素材 = 修改对应组件，无需重新导出图片；不存在位图资源需要压缩
- 体积：全部素材为代码内联，六个场景文件合计约 90 KB（未压缩），无额外网络请求

## 性能与降级

| 约束 | 实现 |
|---|---|
| 离线可用 | 全部 SVG 内联在 JS bundle 中，无网络请求 |
| 缩放不变形 | `viewBox` + `preserveAspectRatio="slice"`，按视口裁切 |
| 低性能模式 | 关闭"氛围动画"或把动画强度设为"关闭"，粒子层直接 `display: none` |
| 素材缺失 | `registry` 里查不到时返回 `null`，背景/角色整层不渲染，界面照常可用 |
| 重绘成本 | 静态 SVG 只在主题/场景变化时重挂载；粒子只有 ≤18 个元素做 `transform/opacity` 动画 |
