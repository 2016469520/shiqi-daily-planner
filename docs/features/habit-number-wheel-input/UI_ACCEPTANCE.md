# UI_ACCEPTANCE: 习惯分钟滚轮连续输入

## 验收清单

### 滚轮交互
- [x] 1. 滚轮连续调整时不得卡顿
- [x] 2. 滚轮期间不得每 1 分钟立即保存
- [x] 3. 停止滚动后 debounce 保存最终值
- [x] 4. 保存中仍可继续调节（不阻塞 UI）
- [x] 5. 旧保存响应不得覆盖新输入
- [x] 6. 滚轮每次调整 1 分钟（方向正确：上+1、下-1）
- [x] 7. 最小值 0，不出现负数

### 保存状态
- [x] 8. 保存状态不挤压布局（固定 w-5 容器）
- [x] 9. 滚动过程中不显示保存图标（不闪烁）
- [x] 10. 停止滚动开始保存时显示 saving spinner
- [x] 11. 保存成功后短暂显示 check
- [x] 12. 保存失败显示 error，点击可重试

### 按钮交互
- [x] 13. + / - 微调每次 1 分钟
- [x] 14. 连续点击 +/- 不每次立即保存
- [x] 15. 停止点击后保存最终值

### 直接输入
- [x] 16. 直接输入仍可用（点击数字进入编辑）
- [x] 17. 输入 Enter/blur 后立即保存
- [x] 18. 非法输入不保存

### 视觉
- [x] 19. 手机端正常（390×844 无横向溢出）
- [x] 20. 深色模式正常
- [x] 21. 未保存的 draft 有轻微视觉区分（琥珀色边框）
- [x] 22. 数字宽度稳定（tabular-nums）

### 功能完整性
- [x] 23. 布尔型习惯不受影响
- [x] 24. 编辑/删除已有记录仍可用
- [x] 25. 习惯统计最终正确
- [x] 26. 刷新后保留最终值
