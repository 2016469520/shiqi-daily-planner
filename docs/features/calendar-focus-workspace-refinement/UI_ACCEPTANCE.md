# UI_ACCEPTANCE — 日历、专注、设置工作区优化

## 日历
- [ ] 任务多时不得重叠或遮挡
- [ ] 同一时段的所有日期列严格对齐
- [ ] 每格最多显示 3 条任务
- [ ] 超出显示"还有 N 项"，数量正确
- [ ] 点击"还有 N 项"可查看全部
- [ ] 周视图小屏横向滚动，不压缩列
- [ ] 小时段表头 sticky
- [ ] 紧凑卡片只显示状态+标题+标签色条+时间/难度图标
- [ ] 完成任务降低权重但可读
- [ ] 今天列有克制高亮

## 任务详情
- [ ] 点击日历任务打开详情
- [ ] 桌面端使用右侧面板，日历保持可见
- [ ] 手机端使用全屏详情
- [ ] 详情可编辑主要字段
- [ ] 完成按钮与详情打开不冲突
- [ ] 拖拽与详情打开不冲突

## 中文化
- [ ] 不出现 morning, afternoon, evening, none, normal
- [ ] 不出现 month, week, day
- [ ] 不出现 0, 1, Sun-Sat
- [ ] 不出现 [object Object], JSON, React 源码

## 专注
- [ ] 左侧导航有"专注"
- [ ] /focus 页面有完整计时器
- [ ] 主页面有明显的大型专注区域
- [ ] 运行中 session 明显可见
- [ ] 计时器使用大型数字和克制进度环
- [ ] 运行/暂停/休息状态清晰
- [ ] 尊重 prefers-reduced-motion

## 每日总结
- [ ] 左侧导航有"每日总结"
- [ ] 点击直接打开今日评价
- [ ] 有"查看历史记录"入口
- [ ] 导航显示填写状态

## 设置
- [ ] 桌面端内容居中，合理利用宽度
- [ ] 无大面积右侧空白
- [ ] 二级导航可用
- [ ] 设置值显示中文
- [ ] 手机端单列，无横向溢出

## 通用
- [ ] 桌面端无横向溢出
- [ ] 手机端无横向溢出
- [ ] 深色模式可读、边框清晰
- [ ] 页面精致但不堆砌装饰
